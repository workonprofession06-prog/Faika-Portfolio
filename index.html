About Me

Who I Am

I'm Faika Khan, a Computer Science graduate (B.Sc., Shri GPM Degree College, 2026) and Frontend Developer who builds responsive, interactive web applications with React 18, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS and Vite.

As a Junior Frontend Developer at Ownmor Global Private Limited, I built and enhanced the interface of a 13-module distributor platform — Dashboard, Referral Management, Leads, KYC & Banking, Shop & Products, Orders & Returns, Network Management, Rank & Achievement, My Wallet, Earnings & Reports, Learning, AI Assistant and AI Manager.

Before that, a 2-year frontend internship at Mumbai Coding Club let me design and ship 15+ responsive, mobile-first websites and web apps for business, education and nonprofit clients — with CSS animations, JavaScript interactions, WordPress customization and cross-browser debugging.

I specialise in reusable React components, dashboards, data tables, charts, forms, modals and drawers, backed by REST API integration and state management. I also have foundational Python, Django, SQL and MySQL knowledge, and I speak English (proficient), Hindi (native) and Spanish (intermediate). I'm looking for a frontend developer role where I can contribute and grow.
